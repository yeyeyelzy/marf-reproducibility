# Baseline boundary

This release intentionally does not redistribute baseline reproduction source
code.  The paper compares MARC with RETAIN, HiTANet, GRAM, CGL, GraphCare,
TCEM, and a local task adaptation of BoxLM.  Reproducers should obtain each
baseline from its official public implementation and follow its license.

All reported baselines use the same patient-level data split, historical
diagnosis-code and visit-interval input boundary, validation-AUROC checkpoint
selection, and five-run aggregation protocol.  The held-out final visit is
used only as the label.  The following table records the minimum information
needed to interpret the comparison; repository revisions are intentionally not
claimed when they are not traceable.

| Method | Official source / paper | Local task and input boundary | Core local training boundary |
| --- | --- | --- | --- |
| RETAIN | Choi et al., 2016 | Binary HF prediction from historical diagnosis codes and visit intervals | Adam, LR 0.001, batch 32, max 20 epochs, patience 5, weight decay 0 |
| HiTANet | Luo et al., 2020 | Same binary task and input boundary | Adam, LR 0.001, batch 32, max 20 epochs, patience 5, weight decay 0 |
| GRAM | Choi et al., 2017 | Same binary task and input boundary | Adam, LR 0.001, batch 32, max 20 epochs, patience 5, weight decay 0 |
| CGL | Lu et al., 2021 | Same binary task and input boundary; no additional patient modalities | Adam, LR 0.001, batch 32, max 20 epochs, patience 5, weight decay 0 |
| GraphCare | Jiang et al., 2024 | Same binary task and input boundary; no additional patient modalities | Adam, LR 0.001, batch 32, max 20 epochs, patience 5, weight decay 0 |
| TCEM | Li et al., 2026 | Same binary task and input boundary | Original staged local setting, max 20 epochs; MIMIC-IV uses gradient accumulation to effective batch 32 |
| BoxLM (local adaptation) | Tan et al., 2025 | Retains box representation, structure--semantic fusion, temporal patient-box update, and volume-similarity prediction; HF is target concept box; no patient text, labs, medications, or labels in the frozen semantic cache | Adam; MIMIC-III LR 0.001, MIMIC-IV LR 0.0001; batch 32; max 20 epochs; patience 5; weight decay 0 |

The BoxLM semantic cache is documented only as generated by a BioBERT-family
model: local materials do not preserve a reliable exact Hugging Face checkpoint
or revision, so this repository does not infer one.
